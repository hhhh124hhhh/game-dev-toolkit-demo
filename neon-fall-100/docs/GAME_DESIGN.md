# 霓虹坠落 - 100层挑战
## Neon Fall 100 - Game Design Document

---

## 一、游戏概述

**名称**: 霓虹坠落 - 100层挑战
**类型**: 2D 平台跳跃 / 下落类游戏
**风格**: 赛博朋克 / 霓虹风格
**平台**: Web (Phaser 3)
**目标受众**: 喜欢挑战性游戏的休闲玩家

---

## 二、核心玩法

### 基础操作
- **左右方向键 / A/D键**: 控制角色左右移动
- **跳跃**: 自动下落，踩平台弹跳
- **目标**: 不断向下跳跃，到达第100层

### 游戏循环
1. 角色从顶部开始自动下落
2. 踩到平台后会弹跳
3. 避开障碍物和危险区域
4. 收集能量和道具
5. 到达更深层数获得更高分数
6. 掉出屏幕底部游戏结束

---

## 三、平台系统 (7种类型)

| 类型 | 颜色 | 特性 | 出现概率 |
|------|------|------|----------|
| 普通 | 青色 | 稳定平台 | 40% |
| 弹跳 | 绿色 | 超级弹跳 | 15% |
| 移动 | 紫色 | 左右移动 | 15% |
| 破碎 | 橙色 | 踩上3秒后碎裂 | 10% |
| 传送 | 粉色 | 随机传送到其他平台 | 5% |
| 冰面 | 蓝色 | 滑动效果 | 10% |
| 消失 | 黄色 | 踩上后闪烁消失 | 5% |

---

## 四、能力系统 (4种能力)

### 蓝色能量 - 二段跳
- 持续时间: 永久 (本局)
- 效果: 空中可再次跳跃
- 视觉: 蓝色光环

### 紫色能量 - 短暂飞行
- 持续时间: 3秒
- 效果: 可以自由控制飞行方向
- 视觉: 紫色翅膀粒子

### 金色能量 - 无敌护盾
- 持续时间: 5秒
- 效果: 免疫所有伤害
- 视觉: 金色护盾环绕

### 红色能量 - 加速下落
- 持续时间: 4秒
- 效果: 下落速度加快，得分翻倍
- 视觉: 红色火焰尾迹

---

## 五、障碍物系统

### 钉子 (红色)
- 出现在平台边缘
- 接触损失1点生命
- 高层出现移动钉子

### 激光束 (红色线条)
- 周期性开关
- 接触直接死亡
- 50层后出现

### 追踪炸弹 (红色圆形)
- 追踪玩家位置
- 爆炸范围伤害
- 70层后出现

### 黑洞 (深紫色)
- 吸引附近玩家
- 接触直接死亡
- 90层后出现

## 六、关卡设计

### 难度曲线
```
层数 1-20:   新手区 (普通平台为主)
层数 21-40:  进阶区 (移动平台增多)
层数 41-60:  挑战区 (破碎平台+障碍物)
层数 61-80:  高难度 (多种机制组合)
层数 81-99:  地狱模式 (全机制组合)
层数 100:    最终Boss战
```

### Boss层设计 (每20层)
- 第20层: 迷你Boss - 追踪弹幕
- 第40层: 中级Boss - 激光阵列
- 第60层: 高级Boss - 分裂攻击
- 第80层: 超级Boss - 多阶段战斗
- 第100层: 最终Boss - 全技能挑战

## 七、成就系统

| 成就名称 | 描述 | 条件 |
|----------|------|------|
| 初次尝试 | 到达第10层 | 层数 >= 10 |
| 渐入佳境 | 到达第25层 | 层数 >= 25 |
| 半程达人 | 到达第50层 | 层数 >= 50 |
| 绝地求生 | 到达第75层 | 层数 >= 75 |
| 百层王者 | 到达第100层 | 层数 >= 100 |
| 能量收集者 | 收集50个能量 | 能量 >= 50 |
| 生存大师 | 存活5分钟 | 时间 >= 300秒 |
| 完美闪避 | 无伤通过20层 | 连续无伤 >= 20 |
| 速度恶魔 | 30秒内到达30层 | 时间 <= 30 && 层数 >= 30 |
| 全能玩家 | 使用所有能力 | 收集全部4种能量 |

## 十、技术实现

### 游戏引擎
- Phaser 3.70+
- Vite 构建工具

### 场景结构
1. BootScene - 资源加载
2. MenuScene - 主菜单
3. GameScene - 游戏主场景
4. PauseScene - 暂停界面
5. GameOverScene - 游戏结束
6. BossScene - Boss战斗

### 核心系统
- PlatformManager - 平台生成系统
- PlayerController - 玩家控制系统
- AbilitySystem - 能力系统
- ScoreSystem - 分数系统
- AchievementSystem - 成就系统
- ParticleSystem - 粒子系统

## 十一、创新点总结

### 相比经典玩法的创新

| 经典元素 | 创新升级 |
|----------|----------|
| 3种平台 | 7种平台类型 |
| 无能力系统 | 4种能力系统 |
| 无Boss战 | 5个Boss层 |
| 简单计分 | 成就系统 |
| 像素风 | 霓虹赛博朋克风 |
| 无特效 | 粒子+光效 |
| 单一难度 | 渐进难度曲线 |

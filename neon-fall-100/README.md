# 霓虹坠落 - 100层挑战

> 是男人就下一百层 - 创新玩法版本

## 游戏介绍

《霓虹坠落》是一款基于经典"是男人就下一百层"玩法的创新平台跳跃游戏。游戏采用赛博朋克/霓虹风格，玩家控制角色不断向下跳跃，躲避障碍物，收集能量，挑战到达第100层！

## 创新玩法

### 平台系统 (7种类型)
| 平台 | 颜色 | 特性 |
|------|------|------|
| 普通 | 青色 | 稳定平台 |
| 弹跳 | 绿色 | 超级弹跳 |
| 移动 | 紫色 | 左右移动 |
| 破碎 | 橙色 | 3秒后碎裂 |
| 传送 | 粉色 | 随机传送 |
| 冰面 | 蓝色 | 滑动效果 |
| 消失 | 黄色 | 踩上消失 |

### 能力系统 (4种能力)
- **二段跳** (蓝色) - 空中再次跳跃
- **短暂飞行** (紫色) - 自由飞行3秒
- **无敌护盾** (金色) - 免疫伤害5秒
- **加速下落** (红色) - 加速下落得分翻倍

### 成就系统
- 初次尝试 - 到达第10层
- 半程达人 - 到达第50层
- 百层王者 - 到达第100层
- 能量收集者 - 收集50个能量
- 生存大师 - 存活5分钟

## 操作说明

| 按键 | 功能 |
|------|------|
| ← → / A D | 左右移动 |
| ↓ / S | 加速下落 |
| 空格 | 二段跳 (需要能力) |
| ESC / P | 暂停游戏 |

## 运行方式

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 技术栈

- **Phaser 3.70+** - 游戏引擎
- **Vite 5** - 构建工具
- **JavaScript ES6+** - 编程语言
